Goal: To allow a user to add an event

Guidelines:
When a user double clicks on a calendar, display a form that allows them to set the start time, end time or duration, and pick the month and day.
Allow the user to select all day or multiple days.
Display any all day events as a light purple. 
Require the user to add a description even if it is longer than the UI can display.
Allow the user to add a note also.
The note could include links so handle HTML gracefully. 
Limit them to only future dates and times.
Update the time selected a light blue.

Result:
The event is saved in the database and displayed on the user calendar with the expected colors.
